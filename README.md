# WocaFuckOff™ v1.1

WocaFuckOff™ je desktopová aplikácia určená na automatizáciu práce s WocaBee.

Projekt obsahuje vlastné GUI, automatické spracovanie úloh, preklady, správu balíkov a pripojenie k Chromium prehliadaču cez CDP.

## 🌐 Automatické preklady

Ak WocaFuckOff™ narazí na neznáme slovíčko, môže ho automaticky preložiť a uložiť.

Pri ďalšom výskyte rovnakého slova použije už uložený preklad.

## 🌐 Chromium / CDP

Automatizácia používa Chromium a Playwright.

Komunikácia s prehliadačom prebieha cez **Chrome DevTools Protocol (CDP)**.

Predvolený debug port:

```text
9222
```
